# **App Name**: Kochi Metro InfoSync

## Core Features:

- Document Upload & Processing: Upload documents (PDF, Excel, Images, Word) with automatic AI-powered summarization, department assignment, urgency tagging (low, medium, high), and deadline setting. Supports both automatic and manual adjustments.
- Automated Workflow & Notifications: Automatically route documents to relevant departments and send notifications to tagged personnel upon upload and processing.
- Centralized Document Dashboard: Provide a dashboard to view document details, status, assigned departments, urgency levels, and deadlines, with integrated audit logs.
- AI Assistant for Document Understanding: An AI assistant provides document summaries, key information extraction, and question answering in both English and Malayalam, supporting both text and audio interaction. It will use a tool to determine if/when specific items of information should be part of the AI Assistant's answer.
- Analytics & Reporting: Generate charts and analytics on total documents, pending reviews, document categories, and workflow progress (e.g., documents resolved vs. pending).
- Multilingual Support: Enable seamless switching between English and Malayalam for the entire application interface and content.
- Secure Authentication: Implement department-specific authentication (e.g., admin@kmrl.ac.in for administrators) to control access to documents and features.

## Style Guidelines:

- Primary color: Deep indigo (#4B0082), evokes knowledge and professionalism. Background: Very light gray (#F0F0F0). Accent color: A vibrant magenta (#FF69B4) for interactive elements.
- Body text: 'Inter', a sans-serif font providing a neutral and modern appearance; Headline Text: 'Space Grotesk', used for larger headlines.
- Use clear and concise icons representing document categories (e.g., engineering, HR, finance) for easy navigation. Icons should adapt to both light and dark themes.
- A clean and intuitive layout with a left sidebar for primary navigation (Dashboard, Documents, Upload, Search, etc.) and a central content area for displaying document information and analytics.
- Subtle transitions and animations to enhance user experience, such as loading indicators and smooth scrolling. Keep animations minimal and professional.
